# Context OS (Lemrock)

This folder is the **handoff-ready context package** for the product this repo relates to.

Goal:
- Keep product context **versioned with code**
- Make it easy for an external builder to pick up the project without repeated calls

Structure (opinionated):
- `00—MASTER CONTEXT.md`
- `01—ROADMAP.md`
- `02—PRIORITY DASH.md`
- `03—RISK REGISTER.md`
- `04—DECISIONS.md`
- `05—PLAYBOOKS.md`
- `runs/YYYY-MM-DD/` — research + artifacts + opportunity briefs
